# Alpha 已知限制

- 仅验证 dsh 0.2.1-rc.5、Node.js 24.22.2。dsh 开发者预览可能破坏接口；未声明兼容其他版本或用户原 Desktop 安装。
- 运行中仅提供 R1/R3 observe/warn。自动拦截、暂停/恢复、单次放行和自动回滚尚未实现。
- 自然会话中 R1/R2 的确证正例不足，R4 为低置信度启发式。浏览器合成测试只验证机制，不证明普遍准确率、任务质量改善或实际 token 节省。
- 原专项评议中的一处中断分类疑点与 R4 未知边界线索仍待复现；标准取消回归与本次结束原因修复不等于这些疑点已解决。
- shell 退出码文本可能被输出仿造；后台、超时、pwsh 不确定退出和外部写入覆盖有限。重复读取仅能依据已观察到的文件操作重置。
- clear/compact、PTC、复合工具、子代理完整生命周期尚未验收。实时模式保守跳过 PTC 子调用及有继承标志的会话。
- 未就绪、未登记或归档会话拒绝处理。跨进程归档导致的缓存清理发生在下一次事件/动作检查；不保证归档瞬间内存清零。
- 官方重复提醒和 Waymark 同时启用仍可能各提醒一次。
- 实时状态、反馈与预算只在内存，重启默认关闭；仅用户可见提示需用 guard status 查看。关闭或切换模式会清除待发提醒。
- observe 和离线分析在本地执行；模型可见 warn 会随 dsh 下一次请求发送。宿主可能另有网络/日志插件，其行为不由 Waymark 控制。
- 内容 token 是字符数 / 4 估算，与实际 tokenizer、账单和上下文窗口占比不同。

反馈请提交 GitHub Issue，优先给出合成最小复现、规则、版本和预期；不要上传原始会话、凭据或私人路径。
