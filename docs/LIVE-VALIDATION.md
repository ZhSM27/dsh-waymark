## 实现范围

- retro 当前/显式 ID/last/导出均经宿主 registry 准入，归档或未登记会话不读正文。last 不调用全库列表，只读取同 cwd 未归档候选，按创建时间选择；读取后及输出前重新检查。
- 默认 off；显式开启 observe/warn，状态在进程内，不恢复历史。按 Agent 隔离，精确参数/错误匹配，结果去重，排除并发，真人输入、编辑、取消及上下文替换等切段。
- R1 两次已结束的同操作、同错误失败后提示；R3 超过 4000 估算 token 后提示。超过 4000 字符的诊断不用于同错分组。PTC 子调用和有继承标志的会话不干预。
- live error.info 映射到已验证适配器，标准 ABORTED 等取消按中断处理；宿主执行前拒绝未经过 dispatch，不计作命令执行失败。
- 下一步注入保留下游决定、全部消息和 request-series 元数据，使用独立 Waymark source；日志到达后补充 seq 证据，未提交则明确标注。
- 每轮最多 1 条、每会话最多 5 条，同一问题去重，默认每条最多 400 字符；记录提示成本估算，状态超限关闭。仅用户可见模式通过 status 查询，不进入模型消息。
- 支持 helpful/unnecessary/uncertain 内存反馈；反馈未冒充认同率。live 配置严格校验，不改离线阈值。
