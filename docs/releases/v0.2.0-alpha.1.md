# Waymark 0.2.0-alpha.1

首次公开 Alpha，面向 DeepSeek Harness 开发者收集反馈。

- 会话复盘：重复失败、重复读取、巨型输出、低置信度用户纠偏。
- 证据轮次、内容估算、AGENTS.md 候选规则及 JSON/Markdown 导出。
- 生产归档保护；显式开启的 R1/R3 实时 observe/warn 与仅用户可见模式。
- 78 项合成测试，以及 rc.5 原生流水线和 DeepSeek 真实模型浏览器验证。

需要 Node.js 24.11+；仅验证 dsh 0.2.1-rc.5。自动拦截与暂停/恢复尚未实现。Alpha 不承诺普遍准确率或实际节省，详见 README 和 docs/KNOWN-ISSUES.md。

安装：`dsh plugin --profile web add -w dsh-waymark@alpha`，随后重启对应 profile。

欢迎使用 Issue 模板反馈误报、漏报和兼容性问题。请只提交合成或脱敏的最小复现，不要上传原始会话、密钥或私人路径。
